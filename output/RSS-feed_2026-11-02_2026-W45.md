> Building change detection (BCD) with very high-resolution (VHR) remotely sensed images (RSIs) is crucial in various remote sensing applications. However, most existing multiscale methods mainly aggregate features from different levels, while the relationships and discriminative differences between adjacent-scale features are seldom explicitly modeled. Existing edge-guided methods generally use building boundaries only as auxiliary constraints, without explicitly exploiting building-edge differences between bitemporal images. In this work, motivated by the idea of utilizing multiscale feature difference, a novel encoder–decoder network called edge-guided adjacent-scale fusion (EGASF) network is proposed for BCD with VHR RSIs.
